# Logto：关闭自助注册，改为仅邀请（实训科平台）

租户：`iiyxny` · 控制台 https://cloud.logto.io/  
应用：`gxstzy-shixun-platform`（原显示名 v2，App ID 未变）

> Cursor 浏览器无法代登你的 Logto 账号，须在本机已登录的控制台完成下列点击。

---

## 一、关闭自助注册

1. 打开 **Sign-in experience**（或 **Sign-in and account → Sign-up and sign-in**，视控制台版本）
2. 找到 **Sign-up** / **Create account**
3. **关闭**「允许用户自行注册 / Enable user registration」
4. 保存

效果：登录页不再出现「创建账号」；陌生人无法自行开户。

若仍看到 Create account，检查是否开了社交注册（GitHub/Google）并一并关掉（校园场景通常不需要）。

---

## 二、仅邀请开户

Logto Cloud 常见两种方式（有则用，没有则用「代建用户」）：

### 方式 A：邀请邮件（Console 有 Invite 时）

1. **User management** → **Invite users** / **Invite**
2. 填写对方邮箱 → 发送
3. 对方点邮件链接设密码或验证码登录
4. 对方打开 https://gxstzy-shixun.ai-builders.space/ 完成首次登录（写入 Turso）

### 方式 B：管理员代建用户

1. **User management** → **Create user** / **Add user**
2. 填邮箱（或手机号，视已开登录方式）
3. 设置临时密码或触发重置邮件
4. 把登录方式告知对方 → 对方首次进平台

## 三、与平台权限后台的衔接

| 步骤 | 在哪做 |
|------|--------|
| 谁能登录 | Logto：邀请 / 代建；关闭注册 |
| 登录后是哪一类人 | 平台 **教务处后台** `/admin/`（改 Turso `role` / `college`） |

首个教务处管理员（二选一）：

1. 环境变量 `ADMIN_EMAILS=你的邮箱@学校.edu.cn`（部署注入或本地 `.env`），用该邮箱登录一次即升为 `jw_admin`
2. 或在 Turso SQL：

```sql
UPDATE users SET role = 'jw_admin', college = NULL, updated_at = datetime('now')
WHERE email = '你的邮箱@...';
```

之后在 https://gxstzy-shixun.ai-builders.space/admin/ 管理其他人角色。

## 四、验收

1. 未邀请邮箱：登录页无法自助注册  
2. 已邀请用户：能登录平台，默认「学生」  
3. `jw_admin`：打开 `/admin/` 能改角色并保存成功  
4. 非管理员打开 `/admin/`：403
