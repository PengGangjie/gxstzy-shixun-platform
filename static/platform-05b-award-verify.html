竞赛核查智能体 · 获奖信息核验

帮教务处核对师生获奖统计表是否按三份红头文件填报准确，并自动回答老师关于竞赛类别、级别、奖金的询问。规则库判定为主、AI 补判为辅：能命中规则的行不调 AI（不花钱），未命中的行才批量送智谱 GLM 判定，且只发送赛事名称、赛项、主办单位、等次、级别五个字段，不含学生姓名等个人信息。

规则知识库（判定依据，唯一口径）

教师技能竞赛管理办法校政字〔2025〕62 号级别体系：A1 / A2 / B1 / B2 / C 学生专业技能竞赛管理办法校政字〔2025〕63 号级别体系：A1 / A2 / B1 / B2 / B3 / C 文化艺术体育类竞赛管理办法校政字〔2025〕64 号国家级 A1/A2 · 省部级 B1/B2 · 市厅级及校级

另附教育厅年度竞赛目录（2024 / 2025 / 2026 在册赛事参考）与三份办法全文，供引用原文条款。新年度目录用脚本一键入库。

核查流程（verify_excel）

  1. 表头自适应
    识别赛事名称 / 赛项名称 / 主办单位 / 获奖等次 / 级别等列，常见别名已内置，各学院表格版式不同也能对齐
  2. 确定性预检
    等次、级别能否识别；年份合理性；空值检查
  3. 规则快路径（不调 API）
    三份办法的类别划分表做赛事名称精确 / 模糊匹配；主办单位提示；选拔赛降一级（如 A1 → B1）
  4. AI 补判
    规则未命中的行批量送智谱 GLM 判定，仅发送五个判定字段，不外泄个人信息
  5. 输出
    带批注副本 + 核查报告，全部落在 output/ 目录，不改动原文件

结果标记

✅ 一致填报的类别 / 级别与规则库判定相符
❌ 不一致附应填级别与条款依据，退回学院修正
⚠️ 需人工确认附原因（如赛事不在册、主办单位存疑）

常用命令

# 表格核查（多 sheet 自适应，输出带批注副本 + 报告到 output/）
python scripts/verify_excel.py "某获奖统计.xlsx"
python scripts/verify_excel.py "表.xlsx" --no-api        # 不调 AI，纯规则判定
python scripts/verify_excel.py "表.xlsx" --sheet 林学院 --limit 20

# 奖状照片批量识别 + 与表格逐条比对
python scripts/ocr_cert.py "奖状图片文件夹"
python scripts/match_cert.py "表.xlsx" "output/奖状识别_xxx.json"

# 新年度教育厅竞赛目录入库
python scripts/build_knowledge.py "新目录.pdf" 2027

怎么用

  • ZCode 技能入口：在 ZCode 里直接说「核查一下这个表」「XX 竞赛什么级别」即可触发；
  • 命令行：在 竞赛核查智能体/ 目录按上方命令执行；
  • AI 补判与奖状识别：需在本机 .env 配置 ZHIPUAI_API_KEY（密钥本机保管，不提交、不外传）；不配置也能跑，未命中的行会标记「需人工审定」。

与获奖情况导航仓的联动

导航仓（11 学院学生技能竞赛获奖驾驶舱）的获奖级别口径与本规则库同源：智能体的规则文件同步生成导航仓的判定标准，两套系统对「A1 / B1 / 等次归一（金奖→一等奖）」等口径保持一致，核查结论可直接对照导航仓数据复核。
